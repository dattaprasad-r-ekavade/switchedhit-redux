# SwitchedHit

Flutter Android **roguelite deckbuilder** about becoming a cricketer.

Street gully → maidans → district → state → franchise trial → international. You are the player, not a franchise owner.

The 3D match-replay spike (`next_app/`, Unity/Next.js plan) is **retired**.
